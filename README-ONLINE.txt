골격왕 격투게임 - 온라인 멀티플레이 구조

1) 서버 폴더에서:
   npm install
   npm start
   기본 포트: 8080

2) 같은 PC 테스트:
   게임의 온라인 서버 주소를 ws://localhost:8080 으로 둡니다.
   한쪽에서 방 만들기 → 6자리 방 코드 생성 → 다른 쪽에서 코드 입력 → 방 참가.

3) 다른 기기/인터넷:
   이 server.js를 외부에서 접근 가능한 Node.js 서버에 배포하고, 게임의 서버 주소를
   ws:// 또는 wss:// 주소로 바꿉니다. HTTPS 게임 페이지에서는 반드시 wss://를 사용하세요.

4) 현재 구조:
   - 2인 방 생성/참가
   - 캐릭터 선택 동기화
   - 맵 선택 동기화
   - 참가자 입력 전달
   - 호스트 권한 게임 상태 스냅샷 전달
   - 연결 종료 감지

싱글/한 기기 2인/연습 모드는 기존대로 유지됩니다.
